개인정보처리방침

yt-uploader · 최종 수정일 2026-09-08

1. 개요

yt-uploader(이하 "본 도구")는 운영자가 본인 소유의 YouTube 채널을 관리하기 위해 사용하는 개인용 도구입니다. 일반 사용자를 대상으로 배포하지 않으며, 운영자 본인 외의 이용자로부터 어떠한 정보도 수집하지 않습니다.

2. 접근하는 정보

본 도구는 Google OAuth 인증을 통해 도구를 실행한 본인 계정의 다음 항목에만 접근합니다.

  • 본인 YouTube 채널에 영상을 업로드하고 공개 일정을 설정하는 권한
  • 본인이 업로드한 영상의 제목·설명·태그·썸네일·자막을 등록하고 수정하는 권한
  • 본인 채널의 재생목록을 구성하는 권한
  • 본인 채널의 조회수·시청 시간 등 지표를 읽는 권한

3. 저장과 보관

인증 자격증명은 도구를 실행하는 로컬 컴퓨터에만 저장되며 외부로 전송되지 않습니다. 본 도구는 서버를 운영하지 않고, 데이터베이스를 두지 않으며, 어떤 정보도 원격에 보관하지 않습니다.

4. 제3자 제공

접근한 정보를 제3자에게 판매·양도·공유하지 않습니다. 광고·분석·추적 목적으로 사용하지 않습니다. 통신은 Google API 서버와 직접 이루어집니다.

5. Google 사용자 데이터 정책

본 도구의 Google API 사용은 제한적 사용 요건(Limited Use)을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 접근 권한 철회

부여한 권한은 언제든지 Google 계정 권한 관리에서 철회할 수 있습니다. 철회 시 로컬에 저장된 자격증명은 즉시 무효가 됩니다.

7. 변경

본 방침이 변경되면 이 페이지에 수정일과 함께 게시합니다.
